# راهنمای فارسی — FPN Tunnel برای اندروید

این برنامه یک کلاینت غیررسمی برای سرویس **Firefox Private Network** موزیلاست: کل اینترنت گوشی از تونل رد می‌شود و می‌توانی کشور خروجی را خودت انتخاب کنی (۳۳ کشور).

## اول این را بدان

برنامه **دو بخش** دارد و هر دو لازم‌اند:

1. **موتور** — داخل برنامه‌ی Termux اجرا می‌شود و به اکانت فایرفاکس تو وصل می‌شود.
2. **اپ FPN Tunnel** — تونل VPN اندروید است و ترافیک را می‌دهد دست موتور.

فایل APK آماده فقط قدمِ «ساختن اپ» را حذف می‌کند؛ راه‌انداختن موتور یک بار لازم است و بدون آن، اپ به‌تنهایی هیچ کاری نمی‌کند. کل راه‌اندازی حدود ۱۰ تا ۱۵ دقیقه طول می‌کشد.

## پیش‌نیازها

- اشتراک فعال Firefox Private Network یا Mozilla VPN روی اکانت فایرفاکس (بدون اشتراک کار نمی‌کند).
- مرورگر **Firefox اندروید** نصب باشد و با همان اکانت واردش شده باشی.
- برنامه‌ی **Termux** — از F-Droid بگیر؛ نسخه‌ی پلی‌استور قدیمی و خراب است.
- **روت (Magisk)** برای روش خودکار. بدون روت هم می‌شود، ولی قدم سشن را باید با کامپیوتر انجام بدهی و موتور را هر بار دستی روشن کنی (قدم ۲، روش ب).

## قدم ۱ — نصب Termux و آماده‌کردن موتور

Termux را باز کن و این دستورها را به‌ترتیب بزن:

```bash
pkg update -y
pkg install -y git nodejs-lts python
git clone https://github.com/msgornami/fpn-tunnel-android
mkdir -p ~/foxhole-android
cp fpn-tunnel-android/engine/* ~/foxhole-android/
```

## قدم ۲ — دادن سشن فایرفاکس به موتور

موتور برای وصل‌شدن به موزیلا به سشن ورود فایرفاکس تو نیاز دارد. فایل سشن فقط روی گوشی خودت می‌ماند و جایی فرستاده نمی‌شود.

**روش الف — با روت (خودکار):**

```bash
python3 ~/foxhole-android/extract_session.py
```

اگر نوشت `WROTE ...` یعنی سشن گرفته شده.

**روش ب — بدون روت (از کامپیوتر):**

1. روی کامپیوتر، با همان اکانت وارد Firefox شو.
2. در پوشه‌ی پروفایل فایرفاکس، فایل `signedInUser.json` را پیدا کن (در ویندوز: `%APPDATA%\Mozilla\Firefox\Profiles\<profile>\`).
3. آن فایل را به گوشی منتقل کن و در Termux بگذار اینجا:
   `~/.mozilla/firefox/foxhole.default/signedInUser.json`

## قدم ۳ — روشن‌کردن موتور

```bash
bash ~/foxhole-android/launch_engine.sh
sleep 3
curl http://127.0.0.1:11081/status
```

اگر چیزی شبیه `{"country":"DE", ...}` دیدی موتور زنده است. تست نهایی خروج:

```bash
curl --socks5-hostname 127.0.0.1:11080 https://www.cloudflare.com/cdn-cgi/trace
```

در جواب باید `loc=DE` (یا کشور انتخابی‌ات) ببینی.

**اختیاری ولی پیشنهادشده:** برنامه‌ی Termux:Boot را از F-Droid نصب کن و این را بزن تا موتور بعد از هر ری‌استارت گوشی خودش برگردد:

```bash
mkdir -p ~/.termux/boot
cp ~/foxhole-android/keepalive.sh ~/.termux/boot/
```

## قدم ۴ — نصب اپ و اتصال

1. از بخش **Releases** همین مخزن، فایل `FpnTunnel.apk` را دانلود و نصب کن (ممکن است لازم شود اجازه‌ی «نصب از این منبع» را به مرورگرت بدهی).
2. اپ **FPN Tunnel** را باز کن.
3. دکمه‌ی **Connect** را بزن و اجازه‌ی VPN را تأیید کن.
4. از منوی **Location** کشور را انتخاب کن؛ انتخاب روی اتصال‌های جدید اعمال می‌شود. برای اعمال فوری روی همه‌چیز، یک بار Disconnect و دوباره Connect بزن.

## مشکلات رایج

- **اپ وصل است ولی هیچ سایتی باز نمی‌شود:** موتور روشن نیست. قدم ۳ را دوباره چک کن؛ مخصوصاً بعد از ری‌استارت گوشی (اگر Termux:Boot نداری، موتور را دستی روشن کن).
- **در فایل `~/foxhole-android/engine.log` خطای errno 110 می‌بینی:** سشن فایرفاکس باطل شده؛ قدم ۲ را دوباره انجام بده.
- **بعضی اعلان‌ها دیر می‌آیند یا یک اپ خاص وصل نمی‌شود:** محدودیت خود سرویس موزیلاست — اتصال به آی‌پی خام (بدون اسم دامنه) و بعضی پورت‌ها را قبول نمی‌کند. برای آن اپ، تونل را موقت خاموش کن.
- **اپ بانکی:** قبل از کار بانکی Disconnect بزن؛ خروجی خارجی ممکن است قفل امنیتی بانک را فعال کند.

## محدودیت‌ها

- سرعت را سرویس موزیلا تعیین می‌کند، نه این برنامه.
- اندروید فقط یک اسلات VPN دارد؛ این تونل جای هر VPN دیگری را می‌گیرد.
- این پروژه غیررسمی است و وابسته به موزیلا نیست؛ موزیلا هر وقت بخواهد می‌تواند سرویسش را تغییر بدهد.
